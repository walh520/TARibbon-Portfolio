# Changelog / 变更记录

## 1.3.0 — GPU cloth, collision, and editor preview

- GPU single-sheet cloth with static hard pins and SceneWind sampling.
- Non-planar, single connected Rest Mesh Bake v2 contract.
- Vertex Color R/G/B authoring contract for pins, wind response, and permeability.
- Sphere, capsule, and one-sided plane collider component.
- Fixed-capacity 64-slot collider upload with timestamped pose history.
- Editor preview lifecycle, temporary source hiding, save/PIE suspension, and VSM-compatible transient rendering.
- Chinese-English setup, authoring, and verification documentation.

This changelog describes the source scope of the release. It is not a substitute for build or runtime validation in the target Unreal project.
